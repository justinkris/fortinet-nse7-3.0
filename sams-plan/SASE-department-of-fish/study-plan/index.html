Purpose

Why this plan exists

This plan prepares Samwise, an experienced Fortinet engineer, for the NSE 7 FortiSASE 26 Architect exam. Each episode gives a Fortinet capability a concrete operational reason to exist — an incident, an audit, an expansion, or a design decision Samwise has to make at the Zoo.

  • Unified SASE, SIA, SPA, SSA
  • Endpoint, agent / agentless, edge devices
  • ZTNA, posture, application publishing
  • SD-WAN steering, ADVPN, dual hub
  • BGP self-healing, FortiSASE as a spoke
  • Multiregion & sovereignty
Session Design

How each episode is run

  • Target duration: 20–30 minutes.
  • Story-led opening establishes the operational problem.
  • Socratic learning is the main phase — one question at a time.
  • Configuration only after the mental model is stable.
  • Troubleshooting reveals evidence gradually.
  • End with 5–10 exam questions and generate the required artefacts.
Adaptive Session Rule

Diagnose first, then choose the mode

At the start of each episode, run a fast diagnostic through the story:

  • Ask Samwise to explain the purpose of the technology.
  • Ask one behaviour-prediction question.
  • Ask for one likely verification step.

Do not raise confidence because an episode was completed. Raise it only when Samwise demonstrates understanding.
