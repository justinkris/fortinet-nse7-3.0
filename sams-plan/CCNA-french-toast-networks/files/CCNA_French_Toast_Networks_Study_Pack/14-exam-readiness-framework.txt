EXAM READINESS FRAMEWORK
CCNA 200-301

READINESS DIMENSIONS
--------------------
1. Explain
2. Predict
3. Configure
4. Verify
5. Troubleshoot
6. Recognise exam traps

DOMAIN GATE
-----------
A domain is considered ready when the learner can:
- Explain the core mental models without notes
- Answer applied questions consistently
- Interpret common CLI output
- Complete configure-and-verify tasks
- Identify common failure modes
- Avoid repeated terminology traps

CONFIDENCE THRESHOLDS
---------------------
★☆☆☆☆ — New or very weak
★★☆☆☆ — Partial recognition
★★★☆☆ — Functional but inconsistent
★★★★☆ — Strong and exam-ready
★★★★★ — Fluent and transferable

FINAL REVIEW PLAN
-----------------
Phase 1 — Domain repair
Review topics below ★★★★☆

Phase 2 — Mixed questions
Mix all six domains.

Phase 3 — CLI interpretation
Use show outputs, tables, and topologies.

Phase 4 — Timed practice
Use realistic exam pacing.

Phase 5 — Final weak-point loop
Return only to repeated errors.

RED FLAGS
---------
- Memorised command without understanding behaviour
- Correct concept but weak output interpretation
- Slow subnetting
- Confusing Layer 2 and Layer 3 decisions
- Treating administrative distance and metric as the same
- Confusing alive, reachable, installed, and preferred
- Missing exact wording such as describe, configure, verify, or interpret

FINAL STORY ASSESSMENT
----------------------
Aussie leads the design and troubleshooting of a new FTN customer network.

The assessment should cover:
- Addressing
- VLANs
- Trunks
- Inter-VLAN routing
- Static routes or OSPF
- DHCP
- NAT
- Wireless
- ACLs and Layer 2 security
- Monitoring and secure management
- Automation concepts
