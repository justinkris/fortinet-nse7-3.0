HOW TO USE
- Generate each image, save it under the exact filename listed, and place all four in an "images/"
  folder beside the HTML file.
- The HTML falls back to a styled placeholder if an image is missing, so the page works either way.
- cast-gallery.png is UNCHANGED from the EP-13 build — reuse the existing file if you generated it.
- Paste SHARED STYLE LINE at the front of every prompt, then the scene text for that image.
- Reuse the CHARACTER SHEET verbatim whenever a character appears, so the cast stays recognisable
  across episodes and artefacts.

cross-hatch shading, flat muted colour fills. Palette limited to cream (#FBF3E6), warm ink brown
(#3A2E28), coral (#E8846B), sky blue (#A9CDE8), butter yellow (#F7DFA0), soft mint (#BFE0C8) and
dusty rose (#F3C5B8). Friendly, hand-drawn, print-book feel — not photorealistic, not 3D, not
glossy corporate vector art. Any text in the image must be short, hand-lettered and legible.
