Get Started

Set up a new Claude Project so Rocco can walk into Halloran's Gym and start UFC-01 with the right instructions and the right knowledge base.

Sourced from UFC-Round1-Study-Pack
1
Create a new Claude Project

In claude.ai, open Projects and create a new project. Give it a memorable name — “Fabric Challenge — UFC Round 1” works well.

2
Paste the Claude Project Instructions

Copy the text below and paste it into the project's Custom Instructions field. The file is live-loaded from files/00-CLAUDE-PROJECT-INSTRUCTIONS.txt — edits to that file appear here on refresh.

00-CLAUDE-PROJECT-INSTRUCTIONS.txtUFC 
Loading 00-CLAUDE-PROJECT-INSTRUCTIONS.txt…

If this text does not update, open files/00-CLAUDE-PROJECT-INSTRUCTIONS.txt directly and copy from there. Some browsers block fetch() on file:// URLs.
3
Upload the Project Knowledge files

Add these files to the project's Knowledge section. The zip contains everything at once — instructions, study plan, story world, sessions, tracking, and reference — or download individual files below.
