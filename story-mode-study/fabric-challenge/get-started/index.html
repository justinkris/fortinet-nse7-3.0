Get Started

Set up a new Claude Project so Rocco can walk into Halloran's Gym and start UFC-01 with the right instructions, the story bibles, and the official Fortinet guide extracts.

Sourced from UFC-Round1-Study-Pack + Fortinet 8.0 guides
1
Create a new Claude Project

In claude.ai, open Projects and create a new project. Give it a memorable name — “Fabric Challenge — UFC Round 1” works well.

2
Paste the Claude Project Instructions

Copy the text below and paste it into the project's Custom Instructions field. The file is live-loaded from files/instructions/00-CLAUDE-PROJECT-INSTRUCTIONS.txt — edits to that file appear here on refresh.

00-CLAUDE-PROJECT-INSTRUCTIONS.txtUFC 
Loading 00-CLAUDE-PROJECT-INSTRUCTIONS.txt…

If this text does not update, open files/instructions/00-CLAUDE-PROJECT-INSTRUCTIONS.txt directly and copy from there. Some browsers block fetch() on file:// URLs.
3
Upload the Project Knowledge files

Add these files to the project's Knowledge section. The pack is split into two bundles — the small story pack (instructions, story world, sessions, tracking) and the larger guides pack (Fortinet 8.0 PDF extracts, UFC-scoped). Or grab any file individually below.

📜 story-pack.zip Instructions, story bibles, plan, sessions, tracking, reference — ~90 KB. ↓ 📚 guides.zip 30 Fortinet 8.0 guide extracts (FortiOS, FortiAnalyzer, FortiDLP) — ~187 MB. Each PDF is under 30 MB. ↓
Claude upload limit: each file uploaded to a Claude project must be under 30 MB. The zips are for local convenience; unzip them and drop the individual files into Claude one at a time (or in batches).
