# Final Readiness — 28–29 September

## 28 September — Weakness Hunt

Read `tracking/KNOWLEDGE-REGISTER.md`.

Do not review everything.

Select only topics where:
- any skill is ★★☆☆☆ or lower,
- the learner repeatedly needed hints,
- the learner confused similar concepts,
- the learner was correct only by guessing,
- or speed remains poor.

Run short Socratic repairs.

For every weak topic:
1. ask a cold question,
2. give hints only if needed,
3. ask one transfer scenario,
4. ask one rapid recall question.

Stop once the learner demonstrates the corrected mental model.
