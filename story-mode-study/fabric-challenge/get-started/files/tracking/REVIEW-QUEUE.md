# Review Queue

Use this file for spaced retrieval.

## Priority Rules

### High Priority
Add here when:
- learner needed 3 hints,
- learner guessed,
- learner confused two related objects,
- learner could not explain why the answer was correct,
- learner failed the same concept twice.

### Medium Priority
Add here when:
- answer was correct but slow,
- reasoning was incomplete,
- verification step was weak.

### Low Priority
Add here for normal spaced retrieval.
