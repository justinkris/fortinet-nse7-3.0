BEHAVIOURS TO TRACK
-------------------
• Identifies what the question is actually testing
• Separates route, policy, session and inspection
• Asks for evidence before making changes
• Explains why distractors are wrong
• Predicts what changes when one condition fails
• Can teach the concept to Junior

CORE REASONING MODEL
--------------------
Identity → Permission → Path → State → Protection → Evidence

TROUBLESHOOTING ORDER
---------------------
1. Define the exact flow.
2. Establish scope.
3. Check route.
4. Check policy.
5. Check session.
6. Check NAT.
7. Check security inspection.
8. Confirm with logs or packet evidence.
9. Change one thing only.
